# 🐻 방글방글 한글 놀이터 (Hangul Playground)

만 6세 유아의 눈높이와 소근육 발달에 맞춰 설계된 반응형 웹 기반 **한글 공부 게임**입니다.  
외부 프레임워크나 빌드 도구, 유료 API, 광고 없이 **순수 HTML5 + CSS3 + Vanilla JavaScript(ES6+)** 만으로 제작되어 **GitHub Pages**에서 즉시 무료 호스팅할 수 있습니다.

---

## ✨ 주요 특징

1. **완전한 독립 구동 (Zero-Dependency)**
   - 외부 CDN 폰트/라이브러리/트래커/광고 없이 100% 자체 코드로 동작합니다.
   - 모든 리소스 경로가 상대 경로(`./`)로 작성되어 `https://username.github.io/repo/` 서브 디렉토리 환경에서도 절대 깨지지 않습니다.

2. **자체 합성 오디오 & 음성 발음 (외부 음원 불필요)**
   - **Web Speech API (`ko-KR`, 기본 속도 `0.85x`)**: 모든 자음, 모음, 결합 글자, 낱말을 또박또박 읽어줍니다. (커스텀 `.mp3` 파일 지정 시 우선 재생하는 폴백 구조 내장)
   - **Web Audio API 신디사이저**: 풍선 터지는 소리(Pop), 실로폰 정답 화음(딩동댕), 따라쓰기 반짝이 하프음, 보상 팡파레(Fanfare), 다정한 격려 사운드를 코드로 실시간 합성합니다.

3. **유아 친화적 UI/UX & 캐릭터 인터랙션**
   - **16:9 가로 모드(Landscape) 최적화**: 세로로 들었을 때 `"화면을 가로로 돌려주세요! 🔄"` 안내 오버레이가 표시됩니다.
   - **터치 오동작 방지**: 더블탭 확대 방지, 롱프레스 텍스트 선택 방지, 바운스 스크롤 방지 및 최소 `64px × 64px` 이상의 큼직한 버튼 영역을 제공합니다.
   - **순수 SVG 아기곰 '보리' 마스코트**: 정답 시 덩실덩실 춤을 추고, 다른 보기를 골랐을 때는 경고음이나 `X` 표시 없이 `"한 번 더 해볼까? 괜찮아!"`라며 따뜻하게 격려합니다.

4. **5단계 한글 커리큘럼 & 미니게임 4종**
   - **1단계**: 기본 모음 (`ㅏ, ㅑ, ㅓ, ㅕ, ㅗ, ㅛ, ㅜ, ㅠ, ㅡ, ㅣ`)
   - **2단계**: 기본 자음 (`ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅊ, ㅋ, ㅌ, ㅍ, ㅎ`)
   - **3단계**: 자음 + 모음 결합 글자 (`가, 나, 다, 라, 고, 노, 모, 무, 수...`)
   - **4단계**: 받침 없는 쉬운 낱말 (`아이, 오이, 나비, 모자, 바나나, 사자, 우유, 나무, 포도, 하마, 기차, 토끼`)
   - **5단계**: 쉬운 받침 낱말 (`달, 곰, 별, 물, 밥, 눈, 공, 집, 꽃, 구름, 사과, 수박`)
   - **미니게임 4종**:
     1. 🎈 **글자 풍선 팡팡!**: 소리를 듣고 떠오르는 풍선 중 알맞은 글자를 터치해 터뜨리기
     2. 🃏 **낱말 짝꿍 찾기**: 귀여운 SVG 그림 카드와 한글 카드를 터치해 매칭하기
     3. ✏️ **손가락 따라쓰기**: Canvas 2D 가이드 글자 위를 손가락으로 슥슥 그리면 무지개 선과 반짝이 효과로 완성
     4. 🧩 **글자 블록 합체!**: 파란색 자음 블록과 분홍색 모음 블록을 터치/드래그하여 글자 완성 (`ㄱ` + `ㅏ` = `가!`)

5. **보상 스티커북 & 부모님 설정 메뉴**
   - **움직이는 스티커 보상**: 5문제를 풀 때마다 축하 꽃가루와 함께 스티커 카드를 1장 획득하며, `[내 스티커북]`에서 터치하면 춤을 춥니다.
   - **부모님 설정 (우측 상단 `⚙️ 부모님 3초꾹` 버튼 3초간 길게 누르기)**:
     - 시작 학습 단계(1~5단계) 선택
     - 음량 및 TTS 발음 속도 조절
     - 15분 쉬는 시간 타이머 켜기/끄기 및 리셋
     - 학습 기록 및 스티커북 초기화 (`localStorage` 자동 저장)

## 🚀 GitHub Pages 배포 가이드 (3분 완성)

별도의 빌드 과정이 없으므로 GitHub 저장소에 올리기만 하면 바로 배포됩니다.

### 1단계: GitHub 저장소 생성 및 코드 푸시
```bash
cd hangul-game
git init
git add .
git commit -m "feat: 만 6세 한글 공부 게임 초기 버전 구축"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/<저장소이름>.git
git push -u origin main
```

### 2단계: GitHub Pages 활성화
1. GitHub 저장소 페이지 상단 탭에서 **[Settings]** 클릭
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Build and deployment** 섹션의 **Source**를 `Deploy from a branch`로 선택
4. **Branch**를 `main` / `/(root)`로 선택 후 **[Save]** 클릭
5. 약 1~2분 뒤 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 접속하면 바로 플레이할 수 있습니다!

### 3단계: 태블릿 / 스마트폰 홈 화면에 앱처럼 추가하기
- **iOS (아이패드/아이폰 Safari)**: 공유 버튼(`[↑]`) 터치 → **[홈 화면에 추가]** 선택 → 전체화면 가로 모드로 실행됩니다.
- **Android (Chrome)**: 우측 상단 메뉴(`⋮`) 터치 → **[홈 화면에 추가]** 또는 **[앱 설치]** 선택 → 전체화면 가로 모드로 실행됩니다.

## ✏️ 부모님을 위한 단어 추가 방법 (`js/words.js`)

`js/words.js` 안의 `CURRICULUM` 객체에 항목을 한 줄 추가하면 4가지 미니게임 모두에 자동으로 반영됩니다:

```javascript
{
  char: "포도",
  tts: "포도",
  word: "포도",
  hint: "송이송이 보라색 포도!",
  icon: "grape",
  jamo: ["ㅍ", "ㅗ"],
  buildTarget: "포"
  // audioSrc: "./audio/podo.mp3" // 직접 녹음한 엄마·아빠 목소리 파일이 있다면 지정 가능!
}
```
